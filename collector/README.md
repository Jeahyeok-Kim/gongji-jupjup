# 공지 줍줍 수집기 (크롬 확장 v1.3.0)

건국대 글로컬캠퍼스 공개 게시판의 공지를 **내 크롬 브라우저가** 정해진 간격으로 모아, 내 컴퓨터의 공지 줍줍 서버로 넘겨 주는 확장입니다.
학교 웹방화벽이 서버·스크립트 요청을 막기 때문에, 실제 브라우저 탭 안에서 평소 게시판을 볼 때와 같은 요청으로 읽습니다.

## 한 번만 하는 준비

1. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → 이 `collector` 폴더 선택 (예전 버전이 있으면 그 카드의 새로고침 버튼)
3. 공지줍줍 폴더의 **`setup_auto.bat`** 을 한 번 실행 → 로그인할 때마다 수신 서버가 켜지고, 매일 아침 전체 처리가 한 번 돈다
   (지금 바로 켜려면 `run_server.bat`)

## 자동으로 일어나는 일

```
[크롬 확장]  6시간마다 학교 사이트 3곳을 백그라운드 탭으로 잠깐 열어 새 글만 받음 → 탭 닫음
     │  (평소에 학교 사이트를 열었을 때도, 받을 때가 됐으면 그 탭에서 조용히 받음)
     ▼
[수신 서버]  http://127.0.0.1:8765  (pipeline/receiver.py, 내 컴퓨터에서만 접속 가능)
     │  collected/ 에 저장 → 1분 기다렸다가
     ▼
[파이프라인] run_all.py --auto : 저장소에 합치기 → 포스터·첨부 읽기 → 로컬 AI 해독·번역 → data/ → 게시
     │
     ▼
[알림]  "새 공지 N건을 받았어요" (제목 3개) → AI 정리가 끝나면 "웹 앱에 반영했어요" 로 바뀜. 누르면 웹 앱이 열림
```

- 서버가 꺼져 있으면 다운로드 폴더에 `kku-notices-날짜.json` 으로 저장하고, 다음 `run_pipeline.bat`(또는 예약 실행)이 찾아 씁니다.
- 툴바 아이콘의 숫자는 마지막 수집에서 새로 받은 글 수, `!` 는 실패한 사이트가 있다는 뜻입니다. 팝업을 열면 숫자가 사라집니다.
- 크롬이 켜져 있어야 수집합니다. 크롬을 껐다 켜면 밀린 수집을 곧바로 한 번 합니다.
- **저장한 공지 마감 알림**: 웹 앱을 내 컴퓨터 서버("웹 앱 열기")로 열어 ★로 저장한 공지는, 크롬 확장이 30분마다 서버에 물어 마감 하루 전과 당일에 한 번씩 알려 줍니다(웹 앱을 닫아 둬도 됨). 누르면 그 공지가 열립니다.
- 알림은 자동 수집(또는 학교 사이트를 열었을 때의 조용한 수집)에서 새 글을 받았을 때만 보냅니다. 직접 "지금 수집"을 누른 경우는 팝업에 바로 보이므로 알리지 않습니다. 고급 설정에서 끌 수 있습니다.

## 보관 기간 (v1.3)

공지를 **한 학기 이상** 가지고 있도록, 게시판마다 정해 둔 기간의 첫날까지 빠짐없이 모읍니다.

- 기본은 **최근 6개월**(오늘이 11월 23일이면 5월 23일 이후 글). 팝업 → 고급 설정 → **공지 보관 기간**에서 **최근 1년**으로 늘릴 수 있습니다.
- 수집할 때 게시판 목록을 앞 쪽부터 읽다가, 고정 공지를 뺀 글 중 첫날보다 오래된 글이 나오면 그 게시판은 멈춥니다(`kkuNextPage`, config.js).
- 처음이거나 기간을 늘렸으면(게시판마다 '어디까지 채웠는지'를 `s:` 기록의 `since` 에 남김) 이미 아는 글이 나와도 멈추지 않고 첫날까지 거슬러 올라가 빈 곳을 채웁니다. 그 뒤로는 예전처럼 새 글만 받습니다(한 쪽이 전부 아는 글이면 멈춤). 중간에 멈추면 기록을 고치지 않아 다음에 다시 채웁니다.
- 내보낼 때도 보관 기간의 글만 보내고, 꾸러미에 `period: { months, since }` 를 적습니다. 파이프라인은 이 기간만큼 웹 앱에 남깁니다(마감이 지난 공지도 '지난 공지'로 보관). 기간을 바꾸면 다음 수집 때 새 기간으로 다시 보냅니다.
- 1.2 이하에서 올린 경우: 처음 한 번은 게시판마다 6개월 치를 다시 확인합니다(이미 가진 글은 다시 저장하지 않음).

## 학기마다 한 번

- **학교 기본 정보**: `www.kku.ac.kr` 탭에서 "학사일정·요람·안내 받기", `rule.konkuk.ac.kr`(규정정보시스템) 탭에서 "학칙·규정 받기".
  받으면 서버로 자동 전달되고 파이프라인이 `data/calendar.js` 와 규정 조문을 갱신합니다.
- **강의 시간표**: `kis.kku.ac.kr` 에 로그인해서 열면 이번 학기 강의 목록을 받아 둡니다(교수 이름·수강 인원은 저장 안 함).
  KIS는 한 계정이 한 곳에서만 로그인되므로 백그라운드로 열지 않습니다.

## 저장하는 것 / 저장하지 않는 것

- 저장: 제목, 날짜, 부서, 조회수, 본문 글자(최대 8,000자), 본문 이미지 주소, 첨부파일 이름·내려받기 주소, 원문 링크
- 저장하지 않음: 작성자 계정 ID 같은 개인 식별자, 로그인 정보, 이음 화면의 내 이름·학번, KIS의 교수 이름·수강 인원
- 권한: `storage`·`unlimitedStorage`(모은 글), `alarms`(예약), `downloads`(서버가 꺼졌을 때 파일 저장), `notifications`(새 공지 알림). 사이트 권한은 학교 사이트 몇 곳과 내 컴퓨터(127.0.0.1) 서버뿐입니다.
- 이음 글에는 `private: true` 가 붙고 파이프라인은 `--with-private` 없이는 처리하지 않습니다(공개 웹앱에 올라가지 않음).

## 학교 서버 배려

- 요청 사이 0.4~0.5초 간격, 게시판당 50건씩. 보관 기간의 첫날보다 오래된 글이 나오면 그 게시판은 멈추고, 두 번째부터는 새 글만(한 페이지가 전부 아는 글이면 멈춤).
- 투데이뉴스는 보관 기간 안에서도 최근 300건까지만, Q&A·교직원 자료실은 기본 해제.
- 방화벽 차단 메시지가 오면 그 사이트는 멈추고 다음 수집 때 다시 시도합니다.
