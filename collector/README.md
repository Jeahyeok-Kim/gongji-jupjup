# KU 공지 수집기 (v0.3.0)

건국대 글로컬캠퍼스 공개 게시판의 글을 **내 크롬 브라우저가** 읽어 JSON 파일로 내보내는 확장 프로그램입니다.
(학교 웹방화벽이 서버·스크립트 요청을 차단하므로, 실제 브라우저 탭 안에서 동작하도록 만들었습니다.)

## 설치

1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더(`manifest.json`이 있는 폴더) 선택

## 사용

1. `https://www.kku.ac.kr/` (또는 국제교육원 `int.kku.ac.kr`, AX융합학부 `ids.kku.ac.kr`) 탭을 연다.
   확장 설치 전에 이미 열려 있던 탭이면 **F5로 새로고침**한다.
2. 툴바의 확장 아이콘 → 수집할 게시판 체크 → **수집 시작**
3. 수집 중에는 **그 탭을 닫지 않는다.** (탭이 닫히면 수집이 멈추고, 다음에 이어서 하면 된다.)
4. **JSON 내보내기** → `kku-notices-날짜.json` 다운로드

## 학교 기본 정보 받기 (학기마다 한 번)

공지와 달리 자주 바뀌지 않는 정보는 한 번 받아 두면 됩니다. 팝업의 **학교 기본 정보** 칸에서:

1. `https://www.kku.ac.kr/` 탭에서 **학사일정·요람·안내 받기**: 연간 주요 학사일정(작년·올해·내년), 최근 3개 학년도 학사요람 PDF 주소, 안내 페이지(주요 전화번호, 학사 종합안내, 장학안내, 통학교통, 예비군, 증명서 발급) 본문
2. `https://rule.konkuk.ac.kr/` (규정정보시스템) 탭에서 **학칙·규정 받기**: `config.js`의 `KKU_REFERENCE.rules`에 적힌 규정(학칙, 글로컬 장학규정, 외국인학생 학사시행내규, 비교과·현장실습·K-MOOC·생활관·교환학생·사회봉사 등)의 최신 조문 전문
3. **기본 정보 내보내기** → `kku-reference-날짜.json`
4. 공지줍줍 폴더에서 `python pipeline/build_reference.py` 실행 → 학사일정(`data/calendar.js`), 요람 쪽수와 규정 조문(`pipeline/regulations.json`)이 최신으로 바뀜

규정이 개정되면 다시 받기만 하면 조문 번호·문장·확인 날짜가 자동으로 바뀝니다. 받을 규정을 늘리려면 `config.js`의 `rules`에 규정 이름을 더하세요.

## 동작 방식

- 게시판당 50건씩 읽고, 요청 사이에 0.4초 간격을 둡니다.
- 두 번째 실행부터는 **새 글만** 가져옵니다 (한 페이지가 전부 이미 아는 글이면 중단).
  이미 저장한 글의 수정 내용까지 반영하려면 "처음부터 전부 다시 수집"을 켭니다.
- 투데이뉴스(4,000건 이상)는 기본 최근 300건까지만 가져옵니다.
- Q&A, 교직원 자료실은 개인 문의가 섞이거나 학생 대상이 아니라서 기본 해제입니다.

## 저장하는 것 / 저장하지 않는 것

- 저장: 제목, 날짜, 부서, 조회수, 본문 텍스트(최대 8,000자), 본문 이미지 주소, 첨부파일 개수·첫 파일명·내려받기 주소, 원문 링크
- v0.2.0: 첨부파일 내려받기 주소(`files`)를 함께 저장합니다. 포스터 이미지와 첨부파일은 파이프라인이 내 PC에서 받아 로컬 AI로 읽습니다.
- 저장하지 않음: 작성자 계정 ID 등 개인 식별자, 비밀번호 필드, 로그인이 필요한 게시판

## 주의

- 공개 게시판 글만 대상입니다. 수집한 데이터를 **웹에 다시 게시할 때**는 원문 전체를 복사하지 말고
  제목·핵심 정보·원문 링크 위주로 가공하세요. 합격자 발표처럼 이름이나 번호가 나오는 공지는 제외하세요.
- 학교 사이트 구조가 바뀌면 동작하지 않을 수 있습니다. 방화벽 차단 메시지가 뜨면 잠시 뒤 다시 시도하세요.
